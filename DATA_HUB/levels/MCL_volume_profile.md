# MCL — volume-profile levels: continuation or bounce?

_Generated by `python3 DATA_HUB/tools/vp_levels.py` (refresh data first with `python3 DATA_HUB/tools/refresh_archive.py --fetch`)._

**How to read this.** For each profile range we found the **low-volume nodes (LVNs)**: thin prices between two heavy ones, usually where one trend leg handed over to the next. Every time price came back to one, we checked what happened first: it **continued** 1.0 ATR further the way it was going, or it **bounced** 1.0 ATR back. 'Both' = one bar did both, so you can't know which came first (it counts as a loss for either trade). 'go-with' / 'fade' = average result, in units of risk and after costs, of trading the continuation or the bounce with stop = target = 1.0 ATR. **Random** = the same test at random prices inside the same range. If LVNs don't differ from random, the LVN is not what decided it.
