# Instructions for every agent working in this repository

1. **This repo is only about the LTA Concepts 2.0 book.** Don't bring in rules, levels or results from
   other projects. Start at `study/README.md`, then `study/CONCEPTS_DIGEST.md`, then `desk/CHARTER.md`.
2. **Page numbers:** the owner's PDF page = the page printed in the book (Chapter 1 = p18). The older `[pN]`
   cites in `study/CONCEPTS_DIGEST.md` are original-PDF pages: subtract 10 before quoting them.
3. **Never commit the book or any part of its text verbatim.** Paraphrase and cite the page.
4. **Paper only. $50,000 account, $2,800 drawdown floor. Flat by 16:00 ET, nothing held 16:00–18:00.**
5. **Never state a price as current unless it was fetched this turn**, and stamp every level with the bar it came from.
6. **The book's win rates have no sample size, payoff or random-entry control.** Never quote them as an edge.
   Any test gets pre-registered in `desk/CHARTER.md` §5, a placebo and a luck bar √(2·ln N).
7. Write so an average trader can follow: plain English, define terms, and always give win rate and payoff together.
